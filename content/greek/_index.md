# Οδηγός API GroupDocs.Comparison: σύγκριση εγγράφων σε .NET Java

![GroupDocs.Comparison Διαφημιστικό](./groupdocs-comparison-net.svg)
[GroupDocs.Comparison Διαφημιστικό](./groupdocs-comparison-net.svg)

Καλώς ήρθατε στον **πλήρη οδηγό σύγκρισης εγγράφων** με το **GroupDocs.Comparison API**. Σε αυτόν τον οδηγό API GroupDocs.Comparison θα ανακαλύψετε πώς να συγκρίνετε προγραμματιστικά Word, PDF, Excel, PowerPoint, εικόνες και πολλές άλλες μορφές τόσο από περιβάλλοντα .NET όσο και Java. Ο οδηγός σας καθοδηγεί μέσω της εγκατάστασης, των βασικών εννοιών, συμβουλών απόδοσης και πραγματικών περιπτώσεων χρήσης, ώστε να προσθέσετε αξιόπιστη λειτουργία diff στις εφαρμογές σας σήμερα.

## Γρήγορες απαντήσεις
- **Τι κάνει το GroupDocs.Comparison API;** Ανιχνεύει και επισημαίνει αλλαγές μεταξύ δύο εγγράφων του ίδιου ή διαφορετικού τύπου.  
- **Ποιες πλατφόρμες υποστηρίζονται;** .NET (Framework, .NET Core, .NET 5/6) και Java (8+).  
- **Χρειάζομαι άδεια για ανάπτυξη;** Μια δωρεάν δοκιμή λειτουργεί για αξιολόγηση· απαιτείται εμπορική άδεια για παραγωγή.  
- **Μπορώ να συγκρίνω αρχεία με προστασία κωδικού;** Ναι – το API δέχεται κωδικούς για το άνοιγμα ασφαλισμένων εγγράφων.  
- **Υπάρχει τρόπος δημιουργίας οπτικών προεπισκοπήσεων;** Απόλυτα, το API μπορεί να δημιουργήσει εικόνες προεπισκόπησης πλάι‑πλάι ή επικάλυψης του αποτελέσματος σύγκρισης.  
- **Πώς μπορώ να συγκρίνω ολόκληρους φακέλους;** Χρησιμοποιήστε τη λειτουργία σύγκρισης φακέλων για επεξεργασία πολλαπλών αρχείων σε μία κλήση, ιδανική για μαζική επικύρωση.  

## Τι είναι το GroupDocs.Comparison API;
Το GroupDocs.Comparison API είναι μια συλλογή βιβλιοθηκών .NET και Java που σας επιτρέπει να συγκρίνετε προγραμματιστικά το περιεχόμενο, τη διάταξη και τη μορφοποίηση δύο εγγράφων. Υποστηρίζει πάνω από 100 τύπους αρχείων, παρέχει λεπτομερές αρχείο αλλαγών και μπορεί να εξάγει το αποτέλεσμα ως νέο έγγραφο, εικόνα ή PDF. Το API λειτουργεί χωρίς την ανάγκη Microsoft Office ή άλλου λογισμικού τρίτων, καθιστώντας το ιδανικό για επεξεργασία στο διακομιστή.

## Γιατί να χρησιμοποιήσετε το GroupDocs.Comparison API;
Το GroupDocs.Comparison API επεξεργάζεται έγγραφα με αρχιτεκτονική ροής που διατηρεί τη χρήση μνήμης κάτω από 50 MB ακόμη και για PDF 500 σελίδων, και μπορεί να συγκρίνει χιλιάδες αρχεία σε έναν φάκελο με λιγότερο από 3 δευτερόλεπτα ανά έγγραφο 100 σελίδων. Προσφέρει **πάνω από 50 μορφές εισόδου και εξόδου**, **ακρίβεια ανίχνευσης αλλαγών 99 %**, ενσωματωμένη διαχείριση κωδικών και πλήρη προσαρμογή των οπτικών στυλ diff—καθιστώντας το μια πιο γρήγορη, ασφαλέστερη εναλλακτική λύση στα εργαλεία χειροκίνητης ανασκόπησης.

## Πώς το GroupDocs.Comparison API διαχειρίζεται μεγάλα έγγραφα;
`LoadOptions` σας επιτρέπει να διαμορφώσετε τη συμπεριφορά φόρτωσης εγγράφων, όπως η ενεργοποίηση της λειτουργίας εξοικονόμησης μνήμης.`  
Το GroupDocs.Comparison API διαβάζει τα αρχεία προέλευσης σε μικρά τμήματα, διατηρώντας τη χρήση μνήμης κάτω από 50 MB ανεξαρτήτως μεγέθους εγγράφου. Η ενσωματωμένη σύγκριση φακέλων επεξεργάζεται τα αρχεία διαδοχικά, επιτρέποντας τη σύγκριση χιλιάδων εγγράφων χωρίς εξάντληση πόρων. Μπορείτε επίσης να ενεργοποιήσετε τη σημαία `LoadOptions` `EnableMemorySaving` για περαιτέρω μείωση της χρήσης RAM διατηρώντας τα πλήρη ακριβή αποτελέσματα diff.

## Πώς να συγκρίνετε δύο έγγραφα χρησιμοποιώντας το GroupDocs.Comparison API;
`Comparer` είναι η κύρια κλάση που εκτελεί τη σύγκριση εγγράφων.  
Φορτώστε τα αρχεία προέλευσης και προορισμού με την κλάση `Comparer`, καλέστε `Compare` και στη συνέχεια αποθηκεύστε το αποτέλεσμα με `Save`. Η κλάση `Comparer` είναι το βασικό στοιχείο που συντονίζει τη φόρτωση, τον υπολογισμό diff και τη δημιουργία εξόδου. Αυτή η ροή τριών βημάτων—φόρτωση, σύγκριση, αποθήκευση—καλύπτει το 99 % των σεναρίων σύγκρισης και λειτουργεί για οποιαδήποτε υποστηριζόμενη μορφή, παρέχοντας μια σαφή και συντηρήσιμη υλοποίηση για προγραμματιστές.

## Ποιοι τύποι αρχείων υποστηρίζει το GroupDocs.Comparison API;
Το GroupDocs.Comparison API υποστηρίζει **πάνω από 50 μορφές εισόδου και εξόδου**, συμπεριλαμβανομένων των DOCX, DOC, ODT, RTF, TXT, XLSX, XLS, ODS, CSV, PPTX, PPT, ODP, PDF, PDF/A, JPG, PNG, BMP, GIF, TIFF, EML, MSG, HTML, EPUB, DJVU και πολλών άλλων. Το API ανιχνεύει αυτόματα κάθε μορφή, εξαλείφοντας την ανάγκη προ‑μετατροπής και εξασφαλίζοντας αδιάλειπτη σύγκριση μεταξύ διαφορετικών τύπων αρχείων.

## Γιατί να επιλέξετε το GroupDocs.Comparison API αντί για άλλα εργαλεία σύγκρισης;
Το GroupDocs.Comparison API προσφέρει κορυφαία ακρίβεια στη βιομηχανία (ανίχνευση αλλαγών 99 %) σε πάνω από 100 μορφές, επεξεργάζεται έγγραφα 500 σελίδων σε λιγότερο από 3 δευτερόλεπτα και περιλαμβάνει ενσωματωμένη ασφάλεια για αρχεία με προστασία κωδικού. Δεν απαιτεί εξωτερικό λογισμικό όπως το Microsoft Office, προσφέρει εκτενείς επιλογές προσαρμογής και παρέχει ισχυρά APIs για .NET και Java, καθιστώντας το ανώτερη επιλογή για επιχειρησιακή σύγκριση εγγράφων.
