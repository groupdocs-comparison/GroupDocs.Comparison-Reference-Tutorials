# Учебник по GroupDocs.Comparison API: сравнение документов в .NET и Java

![Баннер GroupDocs.Comparison](./groupdocs-comparison-net.svg)
[Баннер GroupDocs.Comparison](./groupdocs-comparison-net.svg)

Добро пожаловать в **полное руководство по сравнению документов** с **GroupDocs.Comparison API**. В этом учебнике по GroupDocs.Comparison API вы узнаете, как программно сравнивать Word, PDF, Excel, PowerPoint, изображения и многие другие форматы как в среде .NET, так и Java. Руководство проведёт вас через настройку, основные концепции, советы по производительности и реальные примеры использования, чтобы вы могли добавить надёжную функцию diff в свои приложения уже сегодня.

## Быстрые ответы
- **Что делает GroupDocs.Comparison API?** Он обнаруживает и выделяет изменения между двумя документами одинаковых или разных форматов.  
- **Какие платформы поддерживаются?** .NET (Framework, .NET Core, .NET 5/6) и Java (8+).  
- **Нужна ли лицензия для разработки?** Бесплатная пробная версия подходит для оценки; для продакшн‑использования требуется коммерческая лицензия.  
- **Можно ли сравнивать файлы, защищённые паролем?** Да — API принимает пароли для открытия защищённых документов.  
- **Есть ли возможность генерировать визуальные превью?** Конечно, API может создавать боковые или наложенные изображения превью результата сравнения.  
- **Как сравнить целые папки?** Используйте функцию сравнения папок для обработки нескольких файлов за один вызов, идеально подходит для пакетной валидации.  

## Что такое GroupDocs.Comparison API?
GroupDocs.Comparison API — это набор библиотек для .NET и Java, позволяющих программно сравнивать содержимое, макет и форматирование двух документов. Он поддерживает более 100 типов файлов, предоставляет подробный журнал изменений и может выводить результат в виде нового документа, изображения или PDF. API работает без необходимости установки Microsoft Office или другого стороннего программного обеспечения, что делает его идеальным для серверной обработки.

## Почему стоит использовать GroupDocs.Comparison API?
GroupDocs.Comparison API обрабатывает документы с помощью потоковой архитектуры, позволяющей удерживать использование памяти ниже 50 МБ даже для PDF‑файлов в 500 страниц, и может сравнивать тысячи файлов в папке менее чем за 3 секунды на документ в 100 страниц. Он предлагает **более 50 форматов ввода и вывода**, **точность обнаружения изменений 99 %**, встроенную работу с паролями и полную настройку визуальных стилей diff — что делает его более быстрым и безопасным альтернативой инструментам ручного обзора.

## Как GroupDocs.Comparison API обрабатывает большие документы?
`LoadOptions` позволяет настроить поведение загрузки документа, например включить режим экономии памяти.  
GroupDocs.Comparison API читает исходные файлы небольшими блоками, удерживая потребление памяти ниже 50 МБ независимо от размера документа. Встроенный механизм сравнения папок обрабатывает файлы последовательно, позволяя сравнивать тысячи документов без исчерпания ресурсов. Вы также можете включить флаг `LoadOptions` `EnableMemorySaving`, чтобы ещё больше снизить использование ОЗУ, сохраняя полную точность результатов сравнения.

## Как сравнить два документа с помощью GroupDocs.Comparison API?
`Comparer` — основной класс, выполняющий сравнение документов.  
Загрузите исходный и целевой файлы с помощью класса `Comparer`, вызовите `Compare`, а затем сохраните результат с помощью `Save`. Класс `Comparer` является ядром, координирующим загрузку, вычисление diff и генерацию вывода. Этот трёхшаговый процесс — загрузка, сравнение, сохранение — покрывает 99 % сценариев сравнения и работает с любым поддерживаемым форматом, предоставляя понятную и поддерживаемую реализацию для разработчиков.

## Какие форматы файлов поддерживает GroupDocs.Comparison API?
GroupDocs.Comparison API поддерживает **более 50 форматов ввода и вывода**, включая DOCX, DOC, ODT, RTF, TXT, XLSX, XLS, ODS, CSV, PPTX, PPT, ODP, PDF, PDF/A, JPG, PNG, BMP, GIF, TIFF, EML, MSG, HTML, EPUB, DJVU и многие другие. API автоматически определяет каждый формат, устраняя необходимость предварительного преобразования и обеспечивая бесшовное сравнение различных типов файлов.

## Почему выбрать GroupDocs.Comparison API вместо других инструментов сравнения?
GroupDocs.Comparison API обеспечивает лидирующую в отрасли точность (99 % обнаружения изменений) более чем в 100 форматах, обрабатывает документы в 500 страниц менее чем за 3 секунды и включает встроенную защиту для файлов, защищённых паролем. Он не требует внешнего программного обеспечения, такого как Microsoft Office, предлагает широкие возможности настройки и предоставляет надёжные API как для .NET, так и для Java, что делает его превосходным выбором для корпоративного сравнения документов.

## Часто задаваемые вопросы

**В:** Могу ли я использовать GroupDocs.Comparison API в коммерческом продукте?  
**О:** Да, для продакшн‑развертываний требуется действующая коммерческая лицензия. Бесплатная пробная версия доступна для оценки.

**В:** Поддерживает ли API файлы, защищённые паролем?  
**О:** Абсолютно. Вы можете передать пароль документа при загрузке исходных файлов.

**В:** Какие версии .NET совместимы?  
**О:** API работает с .NET Framework 4.5+, .NET Core 3.1+, .NET 5 и .NET 6+.

**В:** Как API обрабатывает большие документы или массовое сравнение папок?  
**О:** Он использует потоковую обработку и оптимизированные алгоритмы для снижения потребления памяти, а также позволяет сравнивать целые каталоги с помощью функции сравнения папок.

**В:** Есть ли возможность настроить визуальный стиль вывода сравнения?  
**О:** Да, параметры Comparison Options позволяют задавать цвета, стили разметки и форматы вывода для генерируемого diff.
