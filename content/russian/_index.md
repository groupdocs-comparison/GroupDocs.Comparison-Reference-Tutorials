# Руководство по API GroupDocs.Comparison для .NET и Java

![Баннер GroupDocs.Comparison](./groupdocs-comparison-net.svg)
[Баннер GroupDocs.Comparison](./groupdocs-comparison-net.svg)

Добро пожаловать в **полное руководство по сравнению документов** с помощью **GroupDocs.Comparison API**. Это **руководство по GroupDocs.Comparison API** проведёт вас через сравнение Word, PDF, Excel, PowerPoint, изображений и многих других форматов, независимо от того, создаёте ли вы .NET‑веб‑службу или Java‑десктопное приложение. Вы получите пошаговые инструкции, рекомендации по лучшим практикам и советы по производительности, чтобы добавить надёжную функцию diff в свои проекты за считанные минуты.

## Быстрые ответы
- **Что делает GroupDocs.Comparison API?** Он обнаруживает и выделяет изменения между двумя документами одинакового или разного формата.  
- **Какие платформы поддерживаются?** .NET (Framework, .NET Core, .NET 5/6) и Java (8+).  
- **Нужна ли лицензия для разработки?** Бесплатная пробная версия подходит для оценки; для продакшна требуется коммерческая лицензия.  
- **Можно ли сравнивать файлы, защищённые паролем?** Да — API принимает пароли для открытия защищённых документов.  
- **Есть ли возможность генерировать визуальные превью?** Конечно, API может создавать бок‑о‑бок или наложенные превью‑изображения результата сравнения.  
- **Как сравнить целые папки?** Используйте функцию сравнения папок для обработки нескольких файлов за один вызов, идеально подходит для пакетной проверки.  

## Что такое GroupDocs.Comparison API?
`GroupDocs.Comparison API` — набор библиотек, позволяющих разработчикам программно сравнивать содержание, макет и форматирование документов. Он поддерживает **более 50 входных и выходных форматов**, предоставляет детальные журналы изменений и варианты принятия или отклонения модификаций через код.

## Почему стоит использовать GroupDocs.Comparison API?
GroupDocs.Comparison API обеспечивает отраслевое лидерство по точности (99 % обнаружения изменений) более чем **100 типами файлов**, обрабатывает **PDF‑документы в 500 страниц менее чем за 3 секунды** и включает встроенную защиту для файлов, защищённых паролем. Не требует установки внешних офисных пакетов, предлагает широкие возможности кастомизации и работает как на .NET, так и на Java, что делает его идеальным решением для корпоративного сравнения документов.

## Как GroupDocs.Comparison API обрабатывает большие документы?
GroupDocs.Comparison обрабатывает документы с помощью потоковой архитектуры, читающей данные порциями, удерживая потребление памяти ниже **50 МБ** даже для **PDF‑документов в 500 страниц**. Встроенная функция сравнения папок обрабатывает файлы последовательно, позволяя сравнивать тысячи документов без исчерпания ресурсов сервера.

## Как сравнить два документа с помощью GroupDocs.Comparison API?
Класс `Comparer` — основной компонент, выполняющий сравнение документов. Загрузите исходный и целевой файлы с помощью класса `Comparer`, вызовите `Compare`, а затем сохраните результат через `Save`. Этот трёхшаговый процесс — загрузка, сравнение, сохранение — покрывает большинство сценариев сравнения и работает с любым поддерживаемым форматом, предоставляя ясную и поддерживаемую реализацию для разработчиков.

## Какие форматы файлов поддерживает GroupDocs.Comparison API?
GroupDocs.Comparison поддерживает **более 50 входных и выходных форматов**, включая DOCX, DOC, ODT, RTF, TXT, XLSX, XLS, ODS, CSV, PPTX, PPT, ODP, PDF, PDF/A, JPG, PNG, BMP, GIF, TIFF, EML, MSG, HTML, EPUB, DJVU и многие другие. API автоматически определяет каждый формат, устраняя необходимость предварительного преобразования и обеспечивая бесшовное сравнение различных типов файлов.

## Почему выбирать GroupDocs.Comparison API вместо других инструментов сравнения?
GroupDocs.Comparison обеспечивает отраслевое лидерство по точности (99 % обнаружения изменений) более чем **100 форматам**, обрабатывает **документы в 500 страниц менее чем за 3 секунды** и включает встроенную защиту для файлов, защищённых паролем. Не требует внешних программ, таких как Microsoft Office, предлагает обширные возможности кастомизации и предоставляет надёжные API как для .NET, так и для Java, делая его превосходным выбором для корпоративного сравнения документов.

## Часто задаваемые вопросы

**Q:** Могу ли я использовать API GroupDocs.Comparison в коммерческом продукте?  
**A:** Да, для продакшн‑развёртываний требуется действующая коммерческая лицензия. Бесплатная пробная версия доступна для оценки.

**Q:** Поддерживает ли API файлы, защищённые паролем?  
**A:** Абсолютно. Вы можете передать пароль документа при загрузке исходных файлов.

**Q:** Какие версии .NET совместимы?  
**A:** API работает с .NET Framework 4.5+, .NET Core 3.1+, .NET 5 и .NET 6+.

**Q:** Как API обрабатывает большие документы или массовое сравнение папок?  
**A:** Он использует потоковую обработку и оптимизированные алгоритмы для снижения потребления памяти, а также позволяет сравнивать целые каталоги с помощью функции сравнения папок.

**Q:** Можно ли настроить визуальный стиль вывода сравнения?  
**A:** Да, параметры сравнения позволяют задавать цвета, стили разметки и форматы вывода для генерируемого diff.
